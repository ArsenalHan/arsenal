FAQ

这是纯HTML吗？可以直接部署吗？

是的，单文件纯HTML，样式内联在 style 中。你可以直接放到任意静态托管（如 Nginx / GitHub Pages 等）或集成到现有项目。

如何替换成我的品牌与配色？

在 CSS 的 :root 中替换 --brand 与 --brand2 两个变量即可；Logo 与公司名在顶部导航中替换。

我想加“产品对比表/价格卡片/表单”怎么办？

这套结构本来就是模块化的：新增一个 section，按 card 的风格复制即可。你也可以告诉我你的行业与业务目标，我会直接补齐那几个模块。

我想做成多页官网（关于我们/产品/博客）可以吗？

可以。把当前结构拆成多个页面复用同一套 header/footer，或直接改成模板引擎（例如 Flask/Jinja）渲染即可。

准备好把首页做得更“体面 + 能转化”了吗？

把你的行业、目标用户、核心卖点、联系方式填进这套结构，即可得到一个专业的品牌入口。
